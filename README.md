# 📝 写作引擎提示词集合

一套融合三大写作技能的结构化大模型提示词，适用于 ChatGPT、Gemini、Claude 等主流模型，帮助你生成既有思想深度、又有传播力的优质内容。

## 🚀 快速开始

1. 根据你的使用场景选择一个提示词文件
2. 将文件内容完整复制为 System Prompt（或第一条消息）
3. 直接描述你的写作需求，例如：
   - "帮我写一篇关于 AI 焦虑的公众号文章，目标受众是 30 岁的互联网从业者"
   - "把这段技术笔记整理成一篇博客教程"
   - "为小红书写一篇关于早起好处的种草笔记"

## ✨ 核心特性

- **反 AI 味**：内置全面的 AI 痕迹过滤规则，确保输出像人在说话
- **平台自适应**：同一主题自动适配公众号/小红书/抖音的不同表达方式
- **深度思考**：剥洋葱式层层推进，不是要点罗列
- **传播力**：11 个洞见维度确保内容有传播基因
- **可验证**：绝不编造事实，所有声明必须有据可查
